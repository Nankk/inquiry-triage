## ADDED Requirements

### Requirement: LLM レビュー
レビューエージェントは問い合わせ・返信案・規程から、判定（pass / flag）と理由の一覧を構造化データで返さなければならない（SHALL）。判定は専門エージェントに戻さず、承認キューの警告になる。

#### Scenario: 規程違反の疑い
- **WHEN** 返信案が規程の上限を超える補償を約束している
- **THEN** 判定 flag と理由が返り、キュー項目に警告として付く

### Requirement: 決定論的検証
決定論的検証は、引用記事 ID が候補記事に存在すること、禁止表現（返金を確約する語、具体的な期日の約束）を含まないこと、本文が 800 文字以内であること、プレースホルダ（`{{` `}}`）が残っていないことを検証しなければならない（SHALL）。逸脱は警告として付け、自動では直さない。

#### Scenario: 存在しない引用
- **WHEN** 返信案が候補に無い KB-X99 を引用している
- **THEN** 警告「引用記事が候補に無い: KB-X99」が付く

#### Scenario: 禁止表現
- **WHEN** 返信案に「全額返金いたします」が含まれる
- **THEN** 警告「禁止表現: 返金の確約」が付く

### Requirement: 検査の並列実行
LLM レビューと決定論的検証は並列に実行され、両方の結果がキュー項目に付かなければならない（SHALL）。一方が失敗しても他方の結果は残る。

#### Scenario: レビューの失敗
- **WHEN** レビューエージェントの出力が検証に失敗する
- **THEN** キュー項目には決定論的検証の結果と「レビュー失敗」の警告が付く
