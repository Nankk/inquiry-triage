## Why

画面 3 枚の見た目が、近黒の地に青 1 色、丸い札と角丸カードという「AI が出しがちな管理画面の型」そのもので、この構成（一方向の流れ、本番と影の並走、人の承認ゲート）が画面から読み取れない。README のキャプチャ 3 枚は読み手が最初に見るものなので、構成を見せる道具として作り直す。機能と動線は変えない。

## What Changes

- 見た目の世界を「鉄道の運行図表」に置き換える。問い合わせ 1 件を 1 本の列車、各段（分類 → 担当 → 検査 → キュー）を等間隔の駅として一本の線（スジ）で描く。本番は実線、影は破線、失敗や「人が直接対応」は線が止まって終端記号。色は緊急度の 3 色だけ
- 承認キューの一覧の各項目と詳細、追跡画面の段の表示に、このスジを置く。追跡画面の時系列は等間隔の駅の下に所要時間（ms）を数字で添える形にする
- 画面構成も見直す。サイドバーをやめて上部の帯（名前、承認キュー／影の比較のタブ、run 選択）にし、一覧と詳細の左右は保つ。詳細の順序は 本文 → 返信案（本番｜影）→ 警告 → 操作 のまま
- 明るい紙の地（日中の事務所で長時間使う場面から決めた）。方眼は殻だけに敷く
- docs/img のキャプチャ 3 枚を撮り直し、README と architecture.md の画像を差し替える
- 見た目の決定は Impeccable の DESIGN.md（仕上げ時に生成）と surface brief に残し、design.md からリンクする

## Non-goals

- 機能の追加・変更（採用・却下・修正、昇格、run 選択は今のまま）。API と Python 側は触らない
- hash の URL（#/queue/ID、#/inquiry/ID、#/shadow）の変更。scripts/screenshots.py もそのまま
- 依存の追加（react と react-dom のみ。UI ライブラリ、CSS フレームワーク、Web フォントの読み込みは入れない）
- 影の比較画面の表を図に置き換えること（表は表のまま、色と字と余白だけ揃える）
- モバイル専用のレイアウト（1000px 未満で 1 列に畳む今の振る舞いは維持する）

### Modified Capabilities

## Impact

- 変更: `web/src/styles.css`（全面）、`web/src/App.tsx`（殻をサイドバーから上部の帯へ）、`web/src/views/Queue.tsx` / `Inquiry.tsx` / `Shadow.tsx`（構成と部品）、`web/src/components/`（スジの SVG 部品を追加）、`web/src/lib.ts`（段の並びと終端の導出があれば純粋関数として）
